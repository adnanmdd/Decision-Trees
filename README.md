<h2>Decision Trees in Machine Learning</h2>

<p>
  A <strong>Decision Tree</strong> is a supervised machine learning algorithm
  used for both <strong>classification</strong> and <strong>regression</strong>.
  It makes predictions by splitting data into smaller groups based on feature
  values.
</p>

<h3>How It Works</h3>
<ol>
  <li><strong>Start at the root:</strong> Select the best feature to split the data.</li>
  <li><strong>Create branches:</strong> Divide the data based on feature conditions.</li>
  <li><strong>Repeat:</strong> Continue splitting each branch until a stopping condition is reached.</li>
  <li><strong>Make predictions:</strong> Leaf nodes contain the final predicted class or value.</li>
</ol>

<p>
  Common splitting criteria include <strong>Gini Impurity</strong>,
  <strong>Entropy/Information Gain</strong>, and reduction in variance for
  regression trees.
</p>
